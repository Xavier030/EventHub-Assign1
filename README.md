# EventHub - Event Management Platform

## Project Overview
EventHub is a full-stack event management platform that allows users to discover events, register for events, and manage their profiles.


## How to Run
1. Clone repository
   git clone https://github.com/your-repo/eventhub.git
2. Run backend
   mvn spring-boot:run
3. Run frontend
   npm install
   npm run dev

## API Documentation
Swagger UI: http://localhost:8080/swagger-ui/index.html
